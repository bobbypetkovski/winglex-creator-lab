# Winglex Creator Lab

A private creator-evaluation and ROI-planning workspace built with Next.js, TypeScript and Supabase.

Start with [DEPLOY_ON_VERCEL.md](DEPLOY_ON_VERCEL.md) for database setup, app login, Vercel settings, and commands to update your existing GitHub repository.

Features: 22 seeded creators across Poland, Serbia and North Macedonia, TikTok and Instagram profiles on the same shortlist, editable campaign and financial assumptions, package comparisons, named scenarios, actual-result CSV imports, complete workspace backup/restore, and persistent storage with conflict protection. Older single-platform Poland workspaces are upgraded in the app when they are opened.

Forecast inputs are illustrative. Live spreadsheet synchronization and automatic screenshot analysis are not enabled.
